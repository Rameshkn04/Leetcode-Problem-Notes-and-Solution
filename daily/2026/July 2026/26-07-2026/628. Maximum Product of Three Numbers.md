# 628. Maximum Product of Three Numbers

## Problem Statement

Given an integer array `nums`, return the maximum product that can be obtained from any three numbers.

---

## Example 1

**Input**

```text
nums = [1,2,3]
```

**Output**

```text
6
```

**Explanation**

The only possible product is:

```
1 × 2 × 3 = 6
```

---

## Example 2

**Input**

```text
nums = [1,2,3,4]
```

**Output**

```text
24
```

**Explanation**

Choose the three largest numbers:

```
2 × 3 × 4 = 24
```

---

## Example 3

**Input**

```text
nums = [-10,-10,5,2]
```

**Output**

```text
500
```

**Explanation**

Although `5` and `2` are the largest positives, using two negative numbers gives a larger product.

```
(-10) × (-10) × 5 = 500
```

---

# Approach

Sort the array.

There are only two possible candidates for the maximum product:

1. Product of the three largest numbers.
2. Product of the two smallest (most negative) numbers and the largest number.

Return the larger of these two values.

---

# Algorithm

1. Sort the array.
2. Compute:
   - `nums[-1] * nums[-2] * nums[-3]`
   - `nums[0] * nums[1] * nums[-1]`
3. Return the maximum.

---

# Python Solution

```python
class Solution:
    def maximumProduct(self, nums: list[int]) -> int:
        nums.sort()

        return max(
            nums[-1] * nums[-2] * nums[-3],
            nums[0] * nums[1] * nums[-1]
        )
```

---

# Dry Run

### Input

```text
nums = [-10,-10,5,2]
```

After sorting:

```text
[-10,-10,2,5]
```

Candidate 1:

```
5 × 2 × (-10) = -100
```

Candidate 2:

```
(-10) × (-10) × 5 = 500
```

Maximum:

```
500
```

---

# Correctness

The maximum product can only come from:

- The three largest values.
- The largest value combined with the two smallest negative values.

No other combination can produce a larger product.

---

# Complexity Analysis

- **Time Complexity:** `O(n log n)`
- **Space Complexity:** `O(1)`

---

# Key Insight

Two very small (negative) numbers can produce a large positive value when multiplied together.

Therefore, always compare:

```
largest × secondLargest × thirdLargest
```

with

```
smallest × secondSmallest × largest
```

The greater of these two products is the answer.
