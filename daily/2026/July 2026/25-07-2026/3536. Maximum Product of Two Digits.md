# 3536. Maximum Product of Two Digits

## 🟢 Difficulty
**Easy**

## 📖 Problem Statement

Given a **positive integer** `n`, return the **maximum product** of any two digits present in `n`.

> **Note:** The same digit can only be used twice if it appears at least twice in the number.

---

## Examples

### Example 1

**Input**
```text
n = 31
```

**Output**
```text
3
```

**Explanation**

Digits are `[3, 1]`.

Possible product:

- `3 × 1 = 3`

Maximum product is **3**.

---

### Example 2

**Input**
```text
n = 22
```

**Output**
```text
4
```

**Explanation**

Digits are `[2, 2]`.

Possible product:

- `2 × 2 = 4`

Maximum product is **4**.

---

### Example 3

**Input**
```text
n = 124
```

**Output**
```text
8
```

**Explanation**

Digits are `[1, 2, 4]`.

Possible products:

- `1 × 2 = 2`
- `1 × 4 = 4`
- `2 × 4 = 8`

Maximum product is **8**.

---

## Constraints

```text
10 <= n <= 10^9
```

---

# Approach 1: Brute Force

## Intuition

First, extract every digit from the number.

Since a number contains at most **10 digits**, we can simply compare every possible pair of digits and compute their product.

The largest product among all pairs is the answer.

---

## Algorithm

1. Extract all digits of the number into a list.
2. Initialize `ans = 0`.
3. Compare every pair of digits.
4. Update the maximum product.
5. Return the answer.

---

## Dry Run

### Input

```text
n = 124
```

### Step 1: Extract digits

```text
digits = [4, 2, 1]
```

### Step 2: Check every pair

| Pair | Product | Maximum |
|------|---------|----------|
| 4 × 2 | 8 | 8 |
| 4 × 1 | 4 | 8 |
| 2 × 1 | 2 | 8 |

Final answer:

```text
8
```

---

## Code

```python
class Solution:
    def maxProduct(self, n: int) -> int:
        digits = []

        while n > 0:
            digits.append(n % 10)
            n //= 10

        ans = 0
        m = len(digits)

        for i in range(m):
            for j in range(i + 1, m):
                ans = max(ans, digits[i] * digits[j])

        return ans
```

---

## Complexity Analysis

### Time Complexity

Extracting digits:

```text
O(d)
```

Checking every pair:

```text
O(d²)
```

Overall:

```text
O(d²)
```

where `d` is the number of digits.

Since `d ≤ 10`, this is effectively constant time.

### Space Complexity

```text
O(d)
```

for storing the digits.

# Approach 2: Optimized (Two Largest Digits)

## Key Observation

The maximum product will always be obtained by multiplying the **two largest digits**.

Instead of storing every digit and checking all pairs, we only need to keep track of:

- largest digit
- second largest digit

---

## Algorithm

1. Initialize:
   - `first = 0`
   - `second = 0`
2. Extract digits one by one.
3. If the current digit is larger than or equal to `first`:
   - Move `first` to `second`
   - Update `first`
4. Otherwise, if it is larger than `second`, update `second`.
5. Return:

```text
first × second
```

---

## Dry Run

### Input

```text
n = 124
```

Extract digits in reverse order:

```text
4, 2, 1
```

| Current Digit | First | Second |
|---------------|-------|--------|
| 4 | 4 | 0 |
| 2 | 4 | 2 |
| 1 | 4 | 2 |

Answer:

```text
4 × 2 = 8
```

---

## Code

```python
class Solution:
    def maxProduct(self, n: int) -> int:
        first = second = 0

        while n > 0:
            digit = n % 10

            if digit >= first:
                second = first
                first = digit
            elif digit > second:
                second = digit

            n //= 10

        return first * second
```

---

## Complexity Analysis

### Time Complexity

We scan every digit only once.

```text
O(d)
```

where `d` is the number of digits.

Since `d ≤ 10`, this is effectively constant time.

### Space Complexity

```text
O(1)
```

Only two variables are used.

---

# Why the Optimized Approach Works

Suppose the digits are:

```text
[1, 7, 3, 9, 5]
```

The maximum possible product must use the two largest numbers.

Largest digits:

```text
9 and 7
```

Product:

```text
9 × 7 = 63
```

Any product involving a smaller digit will always be less.

For example:

```text
9 × 5 = 45
7 × 5 = 35
3 × 1 = 3
```

Therefore, keeping only the two largest digits is sufficient.
